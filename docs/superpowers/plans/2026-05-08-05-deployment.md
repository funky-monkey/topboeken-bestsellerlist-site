# TopBoeken — Plan 5: Deployment

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deploy the site to the VPS — Nginx config, SSL, PM2 process manager, nightly cron job, and GitHub Actions CD pipeline so every push to `main` automatically deploys.

**Architecture:** Nginx serves the static Astro build and proxies `/admin` + `/api` to the Express CMS. PM2 keeps Express running. A cron job runs the scraper + rebuild at 03:00 nightly. GitHub Actions SSHes into the VPS on every push to `main`.

**Tech Stack:** Ubuntu 22.04 LTS, Node.js 20, Nginx, PM2, Let's Encrypt (Certbot), GitHub Actions

**Prerequisite:** Plans 1–4 complete. A VPS with root SSH access. A domain pointed at the VPS.

### Task 1: VPS provisioning script

**Files:**
- Create: `scripts/setup-vps.sh`

This script is run **once** on a fresh Ubuntu VPS as root. It installs Node.js, PM2, Nginx, Certbot, creates the deploy user, and clones the repo.

- [ ] **Step 1: Write setup-vps.sh**

```bash
#!/usr/bin/env bash
# scripts/setup-vps.sh
# Run once as root on a fresh Ubuntu 22.04 VPS.
# Usage: bash setup-vps.sh yourdomain.nl your@email.com
set -euo pipefail

DOMAIN="${1:?Usage: setup-vps.sh <domain> <email>}"
EMAIL="${2:?Usage: setup-vps.sh <domain> <email>}"
APP_DIR="/home/deploy/topboeken"

echo "=== Installing system packages ==="
apt-get update -qq
apt-get install -y -qq git curl nginx certbot python3-certbot-nginx ufw

echo "=== Installing Node.js 20 ==="
curl -fsSL https://deb.nodesource.com/setup_20.x | bash -
apt-get install -y -qq nodejs

echo "=== Installing PM2 ==="
npm install -g pm2

echo "=== Creating deploy user ==="
id -u deploy &>/dev/null || useradd -m -s /bin/bash deploy
mkdir -p /home/deploy/.ssh
# Copy root's authorized_keys so GitHub Actions can SSH as deploy
cp ~/.ssh/authorized_keys /home/deploy/.ssh/authorized_keys || true
chown -R deploy:deploy /home/deploy/.ssh
chmod 700 /home/deploy/.ssh
chmod 600 /home/deploy/.ssh/authorized_keys

echo "=== Cloning repository ==="
sudo -u deploy git clone https://github.com/YOUR_ORG/topboeken.git "$APP_DIR" || true

echo "=== Setting up directories ==="
sudo -u deploy mkdir -p "$APP_DIR/data" "$APP_DIR/covers" "$APP_DIR/logs" "$APP_DIR/dist"

echo "=== Installing npm dependencies ==="
cd "$APP_DIR" && sudo -u deploy npm ci

echo "=== Initialising database ==="
sudo -u deploy node "$APP_DIR/scripts/init-db.js"

echo "=== Configuring UFW firewall ==="
ufw --force reset
ufw default deny incoming
ufw default allow outgoing
ufw allow ssh
ufw allow http
ufw allow https
ufw --force enable

echo "=== Setting up Nginx ==="
cp "$APP_DIR/nginx/topboeken.conf" /etc/nginx/sites-available/topboeken
# Replace placeholder domain
sed -i "s/DOMAIN_PLACEHOLDER/$DOMAIN/g" /etc/nginx/sites-available/topboeken
ln -sf /etc/nginx/sites-available/topboeken /etc/nginx/sites-enabled/topboeken
rm -f /etc/nginx/sites-enabled/default
nginx -t && systemctl reload nginx

echo "=== Requesting SSL certificate ==="
certbot --nginx -d "$DOMAIN" -d "www.$DOMAIN" --non-interactive --agree-tos -m "$EMAIL"

echo "=== Starting PM2 ==="
cd "$APP_DIR"
sudo -u deploy pm2 start ecosystem.config.js
sudo -u deploy pm2 save
pm2 startup systemd -u deploy --hp /home/deploy | tail -1 | bash

echo "=== Setting up nightly cron ==="
(crontab -u deploy -l 2>/dev/null; echo "0 3 * * * /bin/bash $APP_DIR/scripts/scrape.sh >> $APP_DIR/logs/cron.log 2>&1") | crontab -u deploy -

echo ""
echo "=== Setup complete ==="
echo "Domain: https://$DOMAIN"
echo ""
echo "Next steps:"
echo "  1. SSH in as deploy: ssh deploy@$DOMAIN"
echo "  2. Set environment variables in $APP_DIR/.env"
echo "  3. Run: node $APP_DIR/scripts/hash-password.js yourpassword"
echo "  4. Add ADMIN_PASSWORD_HASH to .env"
echo "  5. Run initial scrape: bash $APP_DIR/scripts/scrape.sh"
```

- [ ] **Step 2: Make executable**

```bash

```

### Task 2: Nginx config

**Files:**
- Create: `nginx/topboeken.conf`

- [ ] **Step 1: Write topboeken.conf**

```nginx
# nginx/topboeken.conf
# Replace DOMAIN_PLACEHOLDER with the actual domain (done by setup-vps.sh)

server {
    listen 80;
    server_name DOMAIN_PLACEHOLDER www.DOMAIN_PLACEHOLDER;
    # Certbot will add HTTPS redirect here after ssl setup
    return 301 https://$host$request_uri;
}

server {
    listen 443 ssl;
    http2 on;
    server_name DOMAIN_PLACEHOLDER www.DOMAIN_PLACEHOLDER;

    # SSL managed by Certbot
    # ssl_certificate / ssl_certificate_key added by certbot

    # Security headers
    add_header X-Frame-Options       "SAMEORIGIN"     always;
    add_header X-Content-Type-Options "nosniff"        always;
    add_header Referrer-Policy       "strict-origin"  always;

    root /home/deploy/topboeken/dist;
    index index.html;

    # Serve cover images from the covers/ directory
    location /covers/ {
        alias /home/deploy/topboeken/covers/;
        expires 30d;
        add_header Cache-Control "public, immutable";
        access_log off;
    }

    # Proxy admin + api to Express CMS
    location ~ ^/(admin|api)/ {
        proxy_pass         http://127.0.0.1:3001;
        proxy_http_version 1.1;
        proxy_set_header   Host              $host;
        proxy_set_header   X-Real-IP         $remote_addr;
        proxy_set_header   X-Forwarded-For   $proxy_add_x_forwarded_for;
        proxy_set_header   X-Forwarded-Proto $scheme;
    }

    # Serve Astro static files
    location / {
        try_files $uri $uri/ $uri.html =404;
        expires 1h;
        add_header Cache-Control "public";
    }

    # Static assets: long cache
    location ~* \.(js|css|woff2|woff|ttf|ico|svg|png|jpg|jpeg|webp)$ {
        expires 1y;
        add_header Cache-Control "public, immutable";
        access_log off;
    }

    # Never index the admin
    location /admin {
        add_header X-Robots-Tag "noindex, nofollow" always;
        proxy_pass http://127.0.0.1:3001;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
    }

    access_log /var/log/nginx/topboeken-access.log;
    error_log  /var/log/nginx/topboeken-error.log;
}
```

### Task 3: GitHub Actions deploy workflow

**Files:**
- Create: `.github/workflows/deploy.yml`

- [ ] **Step 1: Add GitHub Secrets to your repo**

Go to GitHub repo → Settings → Secrets → Actions → New repository secret:
- `VPS_HOST` — IP address or hostname of your VPS
- `VPS_USER` — `deploy`
- `VPS_SSH_KEY` — contents of your private SSH key (the key whose public key is in `/home/deploy/.ssh/authorized_keys`)
- `VPS_APP_DIR` — `/home/deploy/topboeken`

- [ ] **Step 2: Write deploy.yml**

```yaml
# .github/workflows/deploy.yml
name: Deploy to VPS

on:
  push:
    branches: [main]

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - name: Deploy via SSH
        uses: appleboy/ssh-action@v1.0.3
        with:
          host:     ${{ secrets.VPS_HOST }}
          username: ${{ secrets.VPS_USER }}
          key:      ${{ secrets.VPS_SSH_KEY }}
          script: |
            set -euo pipefail
            APP="${{ secrets.VPS_APP_DIR }}"
            cd "$APP"

            echo "--- Pulling latest code ---"
            git pull origin main

            echo "--- Installing dependencies ---"
            npm ci --omit=dev

            echo "--- Building Astro ---"
            npm run build

            echo "--- Restarting Express CMS ---"
            pm2 restart topboeken-api || pm2 start ecosystem.config.js

            echo "--- Reloading Nginx ---"
            sudo nginx -t && sudo systemctl reload nginx

            echo "--- Deploy complete ---"
```

- [ ] **Step 3: Add sudo permission for deploy user to reload nginx**

SSH into VPS as root and run:
```bash
echo 'deploy ALL=(ALL) NOPASSWD: /usr/sbin/nginx -t, /bin/systemctl reload nginx' \
  >> /etc/sudoers.d/deploy-nginx
chmod 440 /etc/sudoers.d/deploy-nginx
```

- [ ] **Step 4: Commit and push to trigger first deploy**

```bash

git commit -m "feat: add GitHub Actions CD pipeline"
git push origin main
```

Expected: Actions tab shows green. SSH into VPS and verify `dist/` is populated.

```
SESSION_SECRET=<random 32+ char string>

```

- [ ] **Step 2: Configure PM2 to load .env**

Update `ecosystem.config.js` to load `.env`:
```js
// ecosystem.config.js
import { config } from 'dotenv';
config();

export default {
  apps: [{
    name: 'topboeken-api',
    script: './server/index.js',
    env_file: '.env',
    watch: false,
    restart_delay: 3000,
    max_restarts: 5,
  }],
};
```

Install dotenv:
```bash
npm install dotenv
```
